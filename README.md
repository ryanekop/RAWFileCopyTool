# RAW File Copy Tool

Automatically filter and copy matching RAW files for photography workflows.

## Download

Download the latest application for macOS, Windows, or Android from the
[Releases](https://github.com/ryanekop/RAWFileCopyTool/releases) page.

## Source code for released versions

This repository is used for application distribution. Each release includes a
`SOURCE-<version>.zip` asset containing the corresponding source code for that
released version. Use that attached asset instead of GitHub's automatically
generated "Source code" archive.
